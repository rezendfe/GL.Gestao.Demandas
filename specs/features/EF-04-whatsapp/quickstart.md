# Quickstart — EF-04

Ainda não há fluxo para exercitar. Quando T401–T403 estiverem feitas:

Subir a API (`dotnet run --project backend/src/Gl.Demandas.Api --launch-profile http`) e o portal (`npm run dev` em `web`). Swagger: http://localhost:5090/swagger. Portal: http://localhost:5173.

1. Como GL / Administrador, gravar um número na subcategoria.
2. Como Cessionário, abrir uma demanda dessa subcategoria.
3. Confirmar o protocolo na resposta e, depois do consumidor, a linha de histórico de envio ou de falha.
