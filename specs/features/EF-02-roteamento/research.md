# Pesquisa — EF-02

Q-09 continua em aberto no PDR §11: quem encerra e quem cancela além do GL / Administrador.

Decisão desta entrega: encerrar é só do GL / Administrador e só a partir de Concluído. Cancelar é só do GL / Administrador, com motivo, e só enquanto o chamado está em aberto. O Cessionário não cancela até existir parâmetro. Não criar cargo novo para conduzir o desfecho.
