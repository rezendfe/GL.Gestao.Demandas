# Quickstart — EF-06

Subir a API (`dotnet run --project backend/src/Gl.Demandas.Api --launch-profile http`) e o portal (`npm run dev` em `web`). Swagger: http://localhost:5090/swagger. Portal: http://localhost:5173.

Senha de demonstração: `Demo@2026`. Cessionário `joao.silva@empresaexemplo.com.br`. GL / Administrador `patricia.lima@gleventos.com.br`. Responsável da Área `responsavel.01@gleventos.com.br`.

1. Abrir o detalhe de um chamado que já mudou de situação.
2. Marcar Linha do tempo e conferir a ordem do mais novo para o mais antigo.
3. Recarregar a página: a opção continua marcada neste navegador.
4. No topo, ao lado do sino, abrir o quadro de auditoria e conferir as ações de quem está logado naquele dia.
5. Com a GL / Administrador, usar «Pesquisar outros usuários», informar início e fim com até 3 meses e filtrar a pessoa. Com Cessionário, essa tela não abre.
6. Na mesma tela, exportar a base inteira para Excel.
